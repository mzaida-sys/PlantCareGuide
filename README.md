# PlantCareGuide

PlantCareGuide is a mobile Android application built to assist users in tracking, organizing, and managing plant care schedules and routines effectively.

## Features

- User Authentication & Profile: Features a splash screen, secure user registration, login, and user profile management.
- Plant Management: Allows users to add new plants, edit existing plant information, and delete plants.
- Categorized Browsing: Organize and filter plants according to specific categories.
- Care Schedules & Details: Display detailed plant information, including watering frequencies and care instructions.
- Interactive List UI: Card-based interface powered by RecyclerView with direct action buttons for editing and deleting plant items.

## Tech Stack & Tools

- Programming Language: Java
- Development Environment: Android Studio
- User Interface:
  - XML Layouts
  - Material Design Components
  - RecyclerView and CardView
- Build Tool: Gradle

## How to Run the Project

1. Clone this repository:
   git clone https://github.com/mzaida-sys/PlantCareGuide.git

2. Open the project in Android Studio.

3. Sync Gradle files with the project.

4. Build and run the application on an Android Emulator or a connected physical device.
